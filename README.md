# ⏱️ DateTime to DateTime

두 날짜·시간을 **초 단위로 바꿔서 그 차이를 구하는** 프로그램입니다. 라이브러리 없이 윤년과 월별 일수를 직접 계산합니다.

## 동작 방식

1. 0년부터 입력 연도 직전까지의 일수를 더함 (윤년: 4의 배수이면서 100의 배수가 아니거나, 400의 배수)
2. 1월부터 입력 월 직전까지의 일수를 더함 (2월은 윤년이면 29일)
3. 일·시·분·초를 모두 초로 환산해 합산
4. 기준일과 비교일의 차이를 출력

```
기준일 2020-02-02 02:02:02
비교일 2021-02-02 02:02:02

→ 기준일보다 31622400 초 지났습니다.
```

비교일이 기준일보다 앞서면 `기준일 보다 과거입니다.`를 출력합니다.

## 실행 방법

```bash
cd CodingTest/src
javac Time_sec.java
java Time_sec
```

날짜는 `main`의 `change(연, 월, 일, 시, 분, 초)` 값을 바꿔서 지정합니다.
